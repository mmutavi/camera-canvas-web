05Background research

How can a camera
follow a hand?

Before building an idea, it helps to learn what the tools can do. These notes explain the main pieces in plain language and link to the sources behind them.

01 / FIND

Hand points

A hand-tracking model can find 21 key points on a hand, such as the wrist and fingertips. The points help a program follow hand movement.

Read Google’s hand-tracking guide ↗
Why does this matter?

The program can use a fingertip’s position as a pointer. It still needs clear rules for when a person wants to draw.

02 / DRAW

Canvas

A canvas is a space on a web page where code can draw shapes, lines, and animations. It can turn points into a moving line.

Read MDN’s Canvas guide ↗
What is one limit?

A canvas does not explain its picture to screen readers by itself. A finished project should add text instructions and other ways to use it.

03 / DESIGN

Make the signal clear

If a line shakes or starts by mistake, drawing feels hard. A good design gives clear feedback and lets people pause or start over.

How could you improve it?

Try steadier tracking, a visible “drawing” signal, and a clear button that erases the canvas.

07Social Studies connection

Technology changes
how we take part.

People make and use tools in communities. A hand-controlled drawing tool raises questions about access, privacy, and who gets to use new technology.

PEOPLE + TECHNOLOGY

Who can join in?

Hands-free controls could give some people another way to interact. But a camera, lighting, movement, or screen can also create barriers. The only way to know is to test with different people and listen to their feedback.

COMMUNITY + PRIVACY

Ask before using a camera

A public art activity should explain when a camera is on, what it sees, whether anything is saved, and how to stop. These are design choices that protect trust.
